# Изменения Loginom Swarm

## 2026-09-25 — bootstrap, не production release

Создана ветка swarm от стабильного Paperclip; она назначена default branch.
Начат перенос инфраструктуры, добавлены правила секретов и реестр upstream,
ручной workflow обновления, проверки политики допуска, отдельные OAuth профили.
Производственный образ Paperclip ещё не заменён. Sampling не запускался.

### Личная публикация 25.09.2026

GitHub App заменён для публикации узлов на отдельный server GitHub CLI OAuth
пользователя kartamyshev-dev. Добавлены установка профиля, повторный вход и
read-only проверка identity/прав. Реальный тестовый push и PR #2 подтверждены.

### Память и инфраструктурная приёмка 25.09.2026

Раздельные настоящие Codex thread ID, trusted hooks, capture journal schema2,
scoped MCP find/read и обратное чтение серверной записи проверены. Полная
резервная копия с новым журналом восстановлена отдельно. Реальный Sol low тест
CLI0.1.16 остановлен на проверке CSV; добавлен постоянный барьер общего аккаунта
и сохранён отчёт в native case Paperclip. Это не успешная приёмка Loginom и не
разрешение обработки узла. Код node coordinator и production rollout ещё впереди.
